# Team Directory Game

An offline Android matching game built in Java. Match a fictional team member's name to a color-coded avatar.

## Portfolio sanitization

This project began as an older hiring exercise. It has been transformed for safe portfolio use: former-company names, endpoints, imagery, real-person records, and network code were removed. All names and avatar data in this version are fictional and stored locally.

## Stack

- Java
- Android SDK and Material Components
- RecyclerView with a responsive grid
- JUnit and AndroidX test scaffolding

Open the project in Android Studio and run the `app` configuration on an Android 8.0+ emulator or device.
