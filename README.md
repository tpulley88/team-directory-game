# Team Directory Game

An offline Android matching game built in Java. Match a fictional team member's name to a color-coded avatar.

> Portfolio note: this is a transformed snapshot of a 2022 hiring exercise, retained to show core Java and Android UI work.

## Portfolio highlights

- Offline, privacy-safe sample data
- RecyclerView grid with click handling
- Portrait and landscape layouts
- Lightweight game-state and answer feedback

## Portfolio sanitization

This project began as an older hiring exercise. It has been transformed for safe portfolio use: former-company names, endpoints, imagery, real-person records, and network code were removed. All names and avatar data in this version are fictional and stored locally.

## Stack

- Java
- Android SDK and Material Components
- RecyclerView with a responsive grid
- JUnit and AndroidX test scaffolding

## Running locally

Requirements:

- JDK 11
- Android Studio with Android SDK 32 available

Open the project in Android Studio and run the `app` configuration on an Android 8.0+ emulator or device. From a configured command line, run `./gradlew test` for the unit tests.

## Privacy and provenance

No credentials, company assets, endpoints, employee records, or externally loaded images are included. All names and visual data are fictional. The public repository starts with this transformed portfolio edition; the historical source history was intentionally not imported.
